# Nexus Community

Независимый Discord-бот для заявок и управления набором участников.

## Установка
1. Python 3.11+, `pip install -r requirements.txt`.
2. Скопируйте `.env.example` в `.env`, укажите `DISCORD_TOKEN`.
3. Пригласите бота со scope `bot` и `applications.commands` и правами отправки сообщений, Embed Links, Manage Roles (если выдаёте роли).
4. Запустите `python bot.py` или используйте Dockerfile.
5. `/form_create` — создать форму, `/form_questions` — вопросы через `|`, `/form_publish` — панель подачи, `/form_list` — список.

Для быстрой синхронизации команд в тестовом сервере задайте `GUILD_ID`; без него команды синхронизируются глобально.

## Ограничения первой версии
- От 1 до 5 вопросов в одной форме (ограничение Discord Modal).
- Сохранение заявок и настроек в SQLite, файл `data/nexus.db` должен находиться на постоянном диске хостинга.
- Пока нет веб-панели, конструктора многостраничных форм, экспорта CSV, чёрного списка и черновиков.
- Повторная заявка запрещена, пока предыдущая находится на рассмотрении.
- Для выдачи роли роль бота должна быть выше назначаемой роли.
- Если бот не может отправить ЛС, результат остаётся виден в канале заявок.
