# Plam v3 — разделение прав

## Установка
Загрузите файлы в корень репозитория. Укажите `DISCORD_TOKEN` в переменных окружения BotHost. При необходимости задайте `GUILD_ID` для быстрой регистрации команд на тестовом сервере. Сохраните постоянный путь `DATABASE_PATH` (по умолчанию `data/plam.db`) и подключите постоянный том на хостинге, иначе данные могут исчезнуть при пересоздании контейнера.

## Пользователь
- `/forms` — список доступных анкет
- `/my_applications` — статусы своих заявок
- `/cancel_application` — отмена заполнения
- Кнопка на панели — заполнение анкеты в ЛС

## Администратор
- `/admin_form_create` — создание формы, выбор канала, роли администратора и роли одобренных
- `/admin_question_add`, `/admin_question_edit`, `/admin_question_delete`, `/admin_question_list`
- `/admin_form_publish`
- `/admin_application_edit`, `/admin_application_delete`

Создавать формы может владелец сервера или участник с Discord-разрешением Administrator. Управлять существующей формой также может назначенная при создании роль `admin_role`. Проверка прав выполняется на сервере при каждой команде и нажатии кнопок. Участник с ролью админа одной формы не получает автоматически доступ к другим формам.

**Важно:** Discord не позволяет боту редактировать чужие сообщения. Исправления ответов сохраняются в базе и публикуются как новые сообщения. Удаление заявки сейчас удаляет её основное сообщение, но не отдельные сообщения с ответами. Команды могут оставаться видимыми обычным пользователям, но их выполнение будет запрещено проверкой прав.

## Проверка
Проверьте `/forms` обычным участником, а `/admin_form_create` — владельцем сервера. Затем создайте форму и назначьте административную роль.

## v4.1 — Поиск партии, единый канал и роли из ENV

Задайте `ADMIN_ROLE_ID`, `MASTER_ROLE_ID`, `PARTY_CHANNEL_ID` в переменных окружения BotHost. Все три обязательны, иначе бот завершит запуск с понятной ошибкой. `PARTY_CHANNEL_ID` — единственный канал для объявлений. Команда `/party_setup` удалена. Старую команду Discord может показывать до синхронизации slash-команд.

- `/party_create` — мастер или администратор создаёт набор в единственном канале.
- `/party_confirm` — автор набора или администратор отмечает записанного участника.
- `/party_cancel` — автор набора или администратор отменяет набор.

Роль `ADMIN_ROLE_ID` даёт административные права **для модуля поиска партии**. Роль `MASTER_ROLE_ID` разрешает создавать наборы. Владелец сервера также считается администратором модуля. Настройки прав анкет из v3 остаются прежними. Сохраните `DATABASE_PATH` на постоянном томе.

## Ограничение публикаций
Повторная публикация набора разрешена не ранее чем через 24 часа после предыдущей публикации, даже если предыдущий набор завершён или отменён.
